# Подключение макросов

Собрать готовый `.xlsm` с уже зашитыми макросами извне Windows нельзя — формат
хранит код в двоичном блоке, который создаёт только сам Excel. Поэтому модули
поставляются файлами, а книга-программа собирается один раз, руками, минут за
пятнадцать. Дальше она копируется на остальные рабочие места как обычный файл.

---

## Важно про кодировку

Импортируйте файлы **только из папки `Для_импорта`**. Они записаны в cp1251 —
той кодировке, в которой редактор VBA читает `.bas` на русской Windows.

Файлы в корне папки `Макросы` лежат в UTF-8: их удобно читать и сравнивать
версии, но редактор VBA превратит из них кириллицу в нечитаемый набор символов.
Причём молча: код просто не скомпилируется, а причина будет неочевидна.

Если после импорта в коде вместо русских слов видны «РїСЂРѕРІ…» — импортировали
не ту копию. Удалите модуль и импортируйте из `Для_импорта`.

---

## Шаг 1. Разложить файлы

Создайте на каждом рабочем месте папку и разложите так:

```
D:\ЛНК\
├── ЛНК_Программа.xlsm      ← создадите на шаге 2
├── ЛНК_Данные.xlsx         ← из папки «Реестры»
├── Шаблоны\                ← 8 файлов .docx из папки «Шаблоны»
├── Готовые\                ← пустая, заполнится сама
└── Копии\                  ← пустая, заполнится сама
```

Программа и данные разделены намеренно: обновление версии заменяет только
`ЛНК_Программа.xlsm`, а `ЛНК_Данные.xlsx` не трогается никогда.

## Шаг 2. Создать книгу программы

1. Откройте Excel, создайте пустую книгу.
2. **Файл → Сохранить как**, тип файла — **Книга Excel с поддержкой макросов
   (*.xlsm)**, имя `ЛНК_Программа`, папка `D:\ЛНК\`.

Обычный `.xlsx` макросы не хранит: сохраните в него — и весь код пропадёт при
закрытии, без предупреждения.

## Шаг 3. Импортировать модули

1. **Alt + F11** — откроется редактор Visual Basic.
2. В дереве слева найдите `VBAProject (ЛНК_Программа.xlsm)`.
3. **File → Import File…** и по очереди выберите из папки `Для_импорта`:

   | Файл | Что делает |
   |---|---|
   | `modConfig.bas` | настройки, пути, поиск колонок по заголовку |
   | `modNumbers.bas` | счётчики регистрационных номеров |
   | `modChecks.bas` | проверки аттестаций, занятости, поверки |
   | `modJournal.bas` | новая запись, регистрация, аннулирование |
   | `modGenerate.bas` | формирование документов Word |
   | `modPrintJournals.bas` | печатные журналы по методам |
   | `modBackup.bas` | резервные копии, пересчёт счётчиков |
   | `modExchange.bas` | обмен дельтами, сборка свода у мастера |
   | `modMedia.bas` | привязка к штатной флешке по серийному номеру |
   | `modDashboard.bas` | Дашборд: что требует внимания сегодня |
   | `modPassport.bas` | сборка Паспорта ЛНК из реестров |
   | `modPPR.bas` | план-график ТО на месяц, заявка на поверку |
   | `modMenu.bas` | построение листа «Меню» |

   Порядок значения не имеет, но импортировать нужно все тринадцать:
   они ссылаются друг на друга.

## Шаг 4. Вставить код книги

Два файла — не модули, а код объектов книги, их импортировать нельзя, только
скопировать текст.

**`ЭтаКнига_код.txt`**: в дереве слева `Microsoft Excel Objects` → двойной
щелчок по **ЭтаКнига** (ThisWorkbook) → вставить содержимое файла в открывшееся
окно справа.

Этот код открывает книгу данных при запуске, показывает просроченную поверку и
делает резервную копию при закрытии.

## Шаг 5. Собрать меню

1. В редакторе VBA нажмите **F5**, в списке выберите `ПостроитьМеню`, **Run**.
   Появится лист «Меню».
2. Вернитесь в редактор, найдите `Microsoft Excel Objects` → двойной щелчок по
   листу **Меню** → вставьте содержимое **`ЛистМеню_код.txt`**.

Пункты меню запускаются **двойным щелчком** по строке. Гиперссылка на макрос в
Excel не создаётся, а кнопки-картинки хуже переживают перенос книги между
машинами, поэтому так.

## Шаг 6. Заполнить настройки

Откройте `ЛНК_Данные.xlsx`, лист **Настройки**:

- **Код рабочего места** — `ПК1` … `ПК6`. Обязательно, книга напомнит.
  Это внутренняя метка, в документах она не печатается; без неё две машины
  заведут записи с одинаковыми номерами, и при слиянии одна затрёт другую.
- **ФИО сотрудника** — подставляется в «Кем внесено».
- **Пути** — если разложили не в `D:\ЛНК\`, поправьте.
- **Общая папка обмена** — сетевая папка или флешка. Без неё не выдаются
  номера, всё остальное работает.

## Шаг 7. Проверить

1. Закройте и снова откройте `ЛНК_Программа.xlsm`. При открытии Excel спросит
   про макросы — **Включить содержимое**.
2. В меню двойным щелчком: **Новая запись в журнале** → должна появиться
   черновая строка в журнале.
3. **Построить печатные журналы**, год 2026 → появятся листы `Печать_ВИК`,
   `Печать_УЗТ` и так далее с мигрированными записями.
4. **Сделать резервную копию** → в папке `Копии` появится файл с датой.

Если на шаге 2 выходит ошибка «Sub or Function not defined» — не импортирован
один из восьми модулей.

## Шаг 8. Разложить на остальные места

Скопируйте всю папку `D:\ЛНК\` на второе и третье рабочее место, на каждом
поправьте в настройках **код рабочего места** и **ФИО**. Импортировать модули
заново не нужно — они уже внутри `.xlsm`.

---

## Если Excel блокирует макросы

Файл скачан из сети — Windows помечает его как небезопасный.
Правый щелчок по `.xlsm` → **Свойства** → внизу галочка **Разблокировать** → ОК.

Прав администратора для этого не требуется.

## Что уже работает и чего пока нет

**Работает:** журнал в широком формате с миграцией, справочник объектов,
выдача номеров через счётчики, проверки перед регистрацией, формирование
документов Word, печатные журналы по методам, локальные резервные копии,
пересчёт счётчиков по журналу, обмен дельтами и сборка свода у мастера,
привязка к штатной флешке, Дашборд, сборка Паспорта ЛНК, месячный
план-график ТО, заявка на поверку на год.

**Пока нет** (последняя очередь работ, раздел 18 ТЗ): годовая печать всех
журналов одной процедурой, обновление версии программы через общую папку,
журнал выдачи оборудования с проверками при выдаче.

**Шаблона для метода МК нет** — при формировании документов система об этом
скажет, документ по МК пока оформляется вручную.

## Честно про проверку

Код проверен статически: парность блоков, существование всех вызываемых
процедур, и главное — что каждый заголовок колонки, который код ищет в книге,
там действительно есть (`scripts/check_vba.py`, 29 контролей). Но **запустить
его в Excel отсюда невозможно**, поэтому первый запуск у вас — это и есть
настоящая проверка. Если что-то упадёт, пришлите текст ошибки и название
процедуры из окна отладки — поправлю.

## Как работает обмен

**Отправка.** «Отправить мои изменения» сравнивает книгу данных со снимком,
сделанным при прошлой отправке, и выгружает во «Входящие» только изменившиеся
строки. Сравнение со снимком, а не отметка «Изменено», выбрано намеренно:
книгу данных можно открыть и без программы, и тогда никакая отметка не
проставится, а снимок ловит любую правку.

**Сборка свода** — действие мастера. Перед применением дельт текущий свод
уходит в `Свод\История` — если слияние пройдёт неудачно, есть точное состояние
«до». Дальше дельты применяются, обработанные переезжают в `Обработанные\ГГГГ-ММ`
и **не удаляются**: их набор — полная история изменений и запасной путь
восстановления данных.

**Спорные правки.** Если строку правили и у вас, и у отправителя, побеждает
более поздняя по времени правки, а **обе версии попадают в отчёт**
`Конфликты\Конфликты_ДАТА.csv`. Молча ничего не теряется.

**Дубли номеров.** После слияния мастер отдельно проверяет, нет ли в пределах
метода и года двух записей с одним номером. Даже теоретический сбой блокировки
счётчика не пройдёт незамеченным.

**Расчётные колонки не переносятся.** Если у получателя в ячейке формула, дельта
её не трогает. Иначе первое же слияние затёрло бы формулы значениями.

**Строка без ID в обмен не попадает** — слияние опознаёт строки только по ID.
Поэтому перед отправкой всё заполненное, но безымянное, его получает
автоматически, и программа об этом сообщает.

### Получение свода

Автоматической замены открытого файла здесь нет: перезапись книги, которая
сейчас открыта, ломает больше, чем чинит. Программа проверит, нет ли у вас
неотправленных изменений, и покажет, что и куда скопировать.

### Флешка

«Зарегистрировать носитель» — действие мастера. Флешка опознаётся по серийному
номеру тома: скопировать папку на другую флешку можно, серийный номер — нет.

Регистрировать нужно **два** носителя: основной и резервный у мастера. С одним
единственным потерянная или умершая флешка останавливает обмен целиком.

Честно про границы: без прав администратора запретить подключение других флешек
нельзя — это делается политиками Windows. Проверка работает на уровне программы
и защищает от ошибки («я думал, эта тоже подойдёт»), а не от намерения.

## Паспорт и план-графики

### Паспорт ЛНК

Из одиннадцати разделов **шесть собираются из данных**: разделы 2 и 5-9 — это
реестры специалистов, аттестаций, СИ и НД. Остальные пять берутся с листа
«Паспорт_постоянная».

Перед сборкой проверяется, заполнено ли обязательное. Если нет — Паспорт **не
собирается**, а показывается список того, чего не хватает, с указанием строки.
Документ с пустыми местами хуже несобранного: пустоту в нём замечают не сразу,
а он идёт в комплект для аттестации лаборатории.

Просроченная поверка в разделах 5-8 не прячется, а помечается красным. Она
всё равно вскроется при проверке — лучше увидеть это заранее.

**Собирается в Excel, а не в Word.** Паспорт — почти сплошные таблицы
переменной длины, в Excel они получаются точнее. Если нужно попасть в
оформление действующей редакции слово в слово — пришлите её файлом, переделаю
на подстановку в шаблон Word.

Первую собранную редакцию стоит один раз сверить с действующей глазами:
опечатка в постоянной части иначе уедет во все следующие редакции.

### План-график ТО на месяц

Считается от **последнего фактически выполненного** обслуживания той же
категории плюс интервал. Если обслуживание не проводилось ни разу, план
считается от начала месяца, а строка помечается красным.

Просроченное показывается **один раз в начале месяца**, а не всей пропущенной
серией: план должен быть выполнимым, иначе его перестают открывать.

ТО-1 считается по рабочим дням — суббота и воскресенье пропускаются.

### Заявка на поверку

Приборы со сроком внутри выбранного года, отсортированные по кварталам —
так заявка сразу читается как график. Приборы с незаполненной датой поверки
**не выпадают молча**: они перечисляются отдельным списком в конце.

### Пересчёт пятилетнего плана

Действующий график 605-2025.ПЛ подписан и переносится как есть. Пересчёт по
периодичности даст другие числа — декадному ТО, например, 36 операций в год
вместо ваших 32. Поэтому пересчёт вынесен в отдельную кнопку с
предупреждением: он для НОВОГО пятилетнего графика, а не для действующего.
