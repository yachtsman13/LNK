# Состав проекта

## Что куда кладётся на рабочем месте

```
D:\ЛНК\
├── ЛНК_Программа.xlsm   ← собирается по инструкции, шаг 2
├── ЛНК_Данные.xlsx      ← из папки «Реестры»
├── Шаблоны\             ← 8 файлов .docx
├── Готовые\             ← пустая, заполнится сама
├── Копии\               ← пустая, заполнится сама
└── Версии\              ← пустая, заполнится сама
```

Флешка готовится кнопкой «Подготовить флешку для обмена» — руками там ничего
создавать не надо.

## Что в архиве

### `Макросы\Для_импорта\` — то, что импортируется в Excel

Восемнадцать модулей в кодировке cp1251 и два файла с кодом объектов книги.
**Импортировать только отсюда**: файлы в `Макросы\` лежат в UTF-8, редактор VBA
превратит из них кириллицу в нечитаемый набор символов.

| Модуль | Что делает |
|---|---|
| `modConfig` | настройки, пути, поиск колонок по заголовку, определение общей папки |
| `modNumbers` | счётчики регистрационных номеров, блокировка, реестр выданных |
| `modChecks` | проверки аттестаций, занятости, поверки |
| `modJournal` | новая запись, регистрация, пакетная регистрация, аннулирование |
| `modGenerate` | формирование документов Word из шаблонов |
| `modPackage` | сборка и печать пакета, нумерация, бирка |
| `modPrintJournals` | печатные журналы по методам |
| `modElectro` | журнал электроинструмента по утверждённой форме |
| `modIssue` | выдача и возврат оборудования |
| `modPPR` | план-график ТО на месяц, заявка на поверку |
| `modPassport` | сборка Паспорта ЛНК из реестров |
| `modExchange` | обмен дельтами, сборка свода у мастера |
| `modMedia` | штатная флешка: подготовка, регистрация, поиск |
| `modBackup` | резервные копии, пересчёт счётчиков |
| `modYearEnd` | закрытие года: все журналы одной процедурой |
| `modUpdate` | обновление версии программы |
| `modDashboard` | Дашборд: что требует внимания сегодня |
| `modMenu` | построение листа «Меню» |

`ЭтаКнига_код.txt` и `ЛистМеню_код.txt` — не модули, их содержимое вставляется
текстом в соответствующие объекты книги.

### `Реестры\ЛНК_Данные.xlsx` — рабочие данные, 21 лист

Журнал в широком формате с мигрированными записями 2026 года, справочник объектов,
реестры СИ, специалистов, аттестаций, НД, обслуживания, план ППР, «Кто где»,
график отпусков, задачи, план-график работ, рекламации, выдача оборудования,
электроинструмент, постоянная часть Паспорта, настройки, списки, сверка миграции,
журнал копирования.

Начинать с листа **«Сверка_миграции»**: там перечислено то, что при переносе
данных требует решения.

### `Шаблоны\` — 8 шаблонов Word

Поля помечены как `#ИмяПоля`. Шаблона для метода МК пока нет — система об этом
предупреждает при формировании.

### `ТЗ\`

`ТЗ_Система_ЛНК.md` — техническое задание, по которому всё сделано.
`Что_дослать.md` — что от вас ещё нужно, по срочности.

### `Макросы\ИНСТРУКЦИЯ.md`

Сборка книги по шагам, замена модулей, работа без сети на флешке, печать пакета,
Паспорт, план-графики, обновление версии.

### `scripts\` — служебное, в Excel не нужно

Чем собиралась книга данных и чем проверяется код. Держать при себе стоит:
если понадобится пересобрать книгу или добавить лист, это делается отсюда.

| Файл | Что делает |
|---|---|
| `build_data.py` | собирает `ЛНК_Данные.xlsx` целиком |
| `migrate.py` | разбор старого журнала, свёртка в широкий формат |
| `check_data.py` | 25 проверок книги: сверка по методам, дубли, связность |
| `check_vba.py` | 64 проверки кода: блоки, имена, циклы вызовов, заголовки колонок |
| `make_cp1251.py` | готовит копии модулей для импорта |
| `lnk_common.py` | оформление книги |

### `Исходники\`

Ваш пятилетний план-график ППР — из него собраны реестр СИ и виды обслуживания.

## Чего в архиве нет

**Готового `.xlsm`.** Формат хранит код в двоичном блоке, который создаёт только
сам Excel; собрать его извне Windows нельзя. Книга собирается один раз руками,
минут за пятнадцать, дальше копируется на остальные места как обычный файл.
