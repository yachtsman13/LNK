# Состав проекта

## Что куда кладётся на рабочем месте

```
D:\ЛНК\
├── ЛНК_Программа.xlsm   ← собирается по инструкции, шаг 2
├── ЛНК_Данные.xlsx      ← из папки «Реестры»
├── Шаблоны\             ← 8 файлов .docx
├── Схемы\               ← картинки схем контроля
├── Сканы\               ← ЛНК, Удостоверения, Поверка
├── Готовые\             ← пустая, заполнится сама
├── Копии\               ← пустая, заполнится сама
└── Версии\              ← пустая, заполнится сама
```

Флешка готовится кнопкой «Подготовить флешку для обмена» — руками там ничего
создавать не надо.

## Что в архиве

### `Макросы\Для_импорта\` — то, что импортируется в Excel

Двадцать три модуля (плюс установщик) в кодировке cp1251 и файл с кодом книги
(`ЭтаКнига_код.txt`). **Импортировать только отсюда**: файлы в `Макросы\` лежат
в UTF-8, редактор VBA превратит из них кириллицу в нечитаемый набор символов.

Импортировать все двадцать три по одному не нужно — `Установка.bas` делает это
сам, см. `ИНСТРУКЦИЯ.md`, шаг 3.

| Модуль | Что делает |
|---|---|
| `Установка` | ставит все остальные модули и код книги одним запуском |
| `modConfig` | настройки, пути, поиск колонок по заголовку, определение общей папки |
| `modNumbers` | счётчики регистрационных номеров, блокировка, реестр выданных |
| `modChecks` | проверки аттестаций, занятости, поверки |
| `modJournal` | новая запись, регистрация, пакетная регистрация, аннулирование |
| `modGenerate` | формирование документов Word из шаблонов, выбор варианта шаблона |
| `modMeasure` | точки замеров по УЗТ и ТВ, настройки АЭ |
| `modCard` | карточка объекта: паспорт вертикально |
| `modKit` | применённые приборы, минимальный комплект на метод |
| `modPlan` | плановые и внеплановые работы, отчёт за период |
| `modScans` | сканы свидетельств и удостоверений в пакет, по 4 на лист |
| `modPackage` | сборка и печать пакета, нумерация, бирка |
| `modPrintJournals` | печатные журналы по методам |
| `modElectro` | журнал электроинструмента по утверждённой форме |
| `modIssue` | выдача и возврат оборудования |
| `modPPR` | план-график ТО на месяц, заявка на поверку |
| `modPassport` | сборка Паспорта ЛНК из реестров |
| `modExchange` | обмен дельтами, сборка свода у мастера |
| `modMedia` | штатная флешка: подготовка, регистрация, поиск |
| `modBackup` | резервные копии, пересчёт счётчиков |
| `modYearEnd` | закрытие года: все журналы одной процедурой |
| `modUpdate` | обновление версии программы |
| `modDashboard` | плитки пульта: что требует внимания сегодня |
| `modMenu` | пульт: плитки, кнопки, обработчик нажатий |

`ЭтаКнига_код.txt` — не модуль, его содержимое вставляется текстом в объект
книги «ЭтаКнига».

### `Реестры\ЛНК_Данные.xlsx` — рабочие данные, 28 листов

Журнал в широком формате с мигрированными записями 2026 года, справочник объектов,
реестры СИ, специалистов, аттестаций, НД, обслуживания, план ППР, «Кто где»,
график отпусков, задачи, план-график работ, рекламации, выдача оборудования,
электроинструмент, замеры, данные протоколов, данные АЭ, применённые средства НК,
минимальный комплект, схемы контроля, таблица твёрдости, постоянная часть Паспорта, настройки,
списки, сверка миграции, журнал копирования.

Выбор везде идёт по читаемому обозначению — наименование объекта с заводским и
регистрационным номерами, прибор с заводским номером, запись журнала датой и
номером акта. Серые колонки с ID заполняются формулами; запоминать цифры не нужно.

Начинать с листа **«Сверка_миграции»**: там перечислено то, что при переносе
данных требует решения.

### `Шаблоны\` — 8 шаблонов Word

Поля помечены как `#ИмяПоля`. Шаблона для метода МК пока нет — система об этом
предупреждает при формировании.

Схемы и картинки вставляются прямо в шаблон. Вариант со своей схемой — отдельный
файл с именем после двух подчёркиваний: `Протокол_УЗТ__Баллон.docx` при общем
`Протокол_УЗТ.docx`. Вариант выбирается по типу объекта; если файла нет, берётся
общий шаблон.

### `ТЗ\`

`ТЗ_Система_ЛНК.md` — техническое задание, по которому всё сделано.
`Что_дослать.md` — что от вас ещё нужно, по срочности.

### `Макросы\ИНСТРУКЦИЯ.md`

Сборка книги по шагам, замена модулей, работа без сети на флешке, печать пакета,
Паспорт, план-графики, обновление версии.

### `scripts\` — служебное, в Excel не нужно

Чем собиралась книга данных и чем проверяется код. Держать при себе стоит:
если понадобится пересобрать книгу или добавить лист, это делается отсюда.

| Файл | Что делает |
|---|---|
| `build_data.py` | собирает `ЛНК_Данные.xlsx` целиком |
| `migrate.py` | разбор старого журнала, свёртка в широкий формат |
| `check_data.py` | 25 проверок книги: сверка по методам, дубли, связность |
| `check_vba.py` | 84 проверки кода: блоки, имена, циклы вызовов, заголовки колонок |
| `check_templates.py` | сверка всех плейсхолдеров шаблонов с колонками книги |
| `make_cp1251.py` | готовит копии модулей для импорта |
| `lnk_common.py` | оформление книги |

### `Исходники\`

Ваш пятилетний план-график ППР (из него собраны реестр СИ и виды обслуживания) и
исходный журнал заключений 2026 года (из него — номера актов).

`ЛНК_Реестры_v2.xlsx` — рабочий файл сборки, не для открытия и правки: это
плоский журнал в промежуточном виде, из которого `build_data.py` разбирает
1001 строку по методам в широкий формат `ЛНК_Данные.xlsx`. Лежит здесь, а не
в «Реестры», нарочно — чтобы не путать со собранной книгой: в «Реестры» только
она, актуальная и единственная. Нужен, только если книгу придётся пересобирать
с нуля; в обычной работе не открывается вовсе.

## Чего в архиве нет

**Готового `.xlsm`.** Формат хранит код в двоичном блоке, который создаёт только
сам Excel; собрать его извне Windows нельзя. Книга собирается один раз руками,
минут за пятнадцать, дальше копируется на остальные места как обычный файл.
