ИМПОРТ ИЗ EXCEL

ЧТО ЭТО
  Пачка новых записей — не через форму по одной, а сразу списком из
  таблицы Excel. Пока для двух справочников: «Объекты» и «Приборы (СИ)».
  Остальные разделы (журнал, специалисты) — позже, если понадобится.

КАК ПОЛЬЗОВАТЬСЯ
  1. В разделе «Объекты» или «Приборы (СИ)» — кнопка «⤓ Шаблон для
     импорта». Скачается пустой .xlsx с колонками, которые совпадают с
     полями карточки (те же подписи, что при добавлении записи вручную).
  2. Заполните строки в Excel. Порядок колонок можно менять — они
     сопоставляются по ТЕКСТУ заголовка, а не по номеру; но сами
     заголовки менять не надо, иначе колонка не опознается.
  3. Кнопка «⬆ Импорт из Excel» — выберите заполненный файл. Программа
     покажет, сколько строк нашла, и спросит подтверждение.
  4. Строки без наименования (пустой хвост шаблона) пропускаются молча.

ЭТО ТОЛЬКО ДОБАВЛЕНИЕ
  Импорт не заменяет и не трогает существующие записи — только
  добавляет новые. Если загрузили файл дважды или часть строк уже была
  в справочнике — появятся повторы. Раздел «Проверка данных» теперь
  умеет находить: одинаковый заводской/регистрационный номер у разных
  карточек — это ошибка (номер не может повторяться); одинаковое
  наименование без номеров вообще — только наблюдение, может быть и
  нормой.

ЧЕГО ИМПОРТ НЕ ДЕЛАЕТ
  Не читает вашу исходную книгу Excel напрямую — там формулы и особая
  разметка, под которую собран отдельный скрипт (export_json.py), а не
  форма для ручного заполнения. Формат импорта — только свой
  шаблон-таблица.

ТЕХНИЧЕСКАЯ ОГОВОРКА
  Разбор .xlsx — свой, без библиотек (ZIP-каталог руками, распаковку
  делает браузер, DecompressionStream). Нужен современный Chrome или
  Edge — если браузер старый, программа честно скажет, что не умеет
  распаковать файл, а не сделает вид, что импорт прошёл.
