ОБМЕН МЕЖДУ РАБОЧИМИ МЕСТАМИ (без сети, через файлы)

ОДИН РАЗ НА КАЖДОМ МЕСТЕ
  Вкладка «Обмен файлами» → задайте КОД МЕСТА: М1, М2, М3 … (у каждого свой).
  На месте мастера поставьте галочку «Мастер (собирает свод)».
  Код входит в номер новых записей — поэтому места не затирают друг друга.

КАК ХОДЯТ ДАННЫЕ
  1. Каждое место: «Выгрузить» → получается файл
     «Обмен ЛНК 2026-09-09 (М2).json». Относите его мастеру (флешка/общая папка).
  2. Мастер: «Принять файлы» → выбирает файлы всех мест сразу.
     Получается общий журнал — свод.
  3. Мастер: «Выгрузить» → раздаёт файл-свод обратно. Каждое место его
     «Принимает» и видит общую картину.

ПОДПИСЬ ФАЙЛОВ (с версии 4.01)
  Файлы обмена, резервные копии и файлы переезда подписываются на том месте,
  где их выгрузили. Это защита от изменения файла после выгрузки. Содержимое
  JSON не шифруется — не передавайте его посторонним.

  На вкладке «Обмен» показан ОТПЕЧАТОК КЛЮЧА этого места. При первом файле
  с другого места сверьте его с отпечатком на экране отправителя (лично или
  по телефону) и только потом подтвердите доверие. Дальше проверка идёт сама.

  Если место прислало файл с другим ключом, ещё раз сверьте новый отпечаток.
  Это бывает после переезда или очистки хранилища браузера, но может быть и
  подменой. Для смены ключа руководитель вписывает «СМЕНИТЬ». Закрытый ключ
  в файлы не входит и при переезде не переносится.

  Старые файлы без подписи можно принять только после отдельного
  предупреждения — это оставлено для перехода с версий до 4.01. Файл нового
  формата без подписи, с чужим ключом или изменённый после выгрузки программа
  отклоняет. При чтении общей папки повреждённый новый файл не заслоняет
  исправный более старый.

ЧТО ПРИ СЛИЯНИИ
  • Новая запись (её ещё нет) — добавляется.
  • Та же запись изменена на другом месте — берётся более СВЕЖАЯ (по времени
    правки). Ваши записи при приёме не теряются.
  • Базовые записи, которые никто не трогал, не задваиваются.
  Проверено: приём файла с 315 базовыми + чужой записью добавляет только
  чужую; повторный приём того же файла не меняет ничего.

ФАЙЛЫ
  Обычные документы с понятным именем, лежат в папке «Обмен». Коллега их не
  спутает и случайно не испортит. Подпись обнаружит ручную правку JSON.

УДАЛЕНИЕ (переносится)
  Удалили запись на одном месте — при обмене она скрывается и у других.
  Внутри запись не выбрасывается сразу, а помечается удалённой (со временем
  удаления), чтобы удаление можно было перенести файлом. Защита от потерь:
  если ТУ ЖЕ запись где-то изменили ПОЗЖЕ удаления — побеждает правка, и
  запись остаётся. То есть устаревшее удаление не стирает свежую чужую работу.

СПРАВОЧНИКИ (обмениваются вместе с журналом)
  Объекты, приборы (СИ) и специалисты теперь тоже редактируются (кнопка
  «Добавить», правка и удаление в карточке) и уходят в тот же файл обмена.
  Слияние и перенос удаления — по тем же правилам, что у журнала.
  Один файл «Обмен ЛНК …» несёт всё: журнал + три справочника.

РЕЗЕРВНАЯ КОПИЯ ВСЕЙ БАЗЫ (вкладка «Обмен», внизу)
  «Сохранить копию» — в один файл уходит ВСЁ: журнал и три справочника.
  Нужна на два случая: память браузера очистили, или переносите всё на
  другой компьютер. Раз в день — достаточно.
  «Восстановить из копии» ЗАМЕНЯЕТ данные (а не сливает, как приём обмена).
  Программа сначала проверит подпись, покажет, что было и что станет, и
  переспросит.

  Разница простыми словами:
    Обмен       — сложить работу разных мест вместе (слияние).
    Копия       — вернуть своё состояние как было (замена).
