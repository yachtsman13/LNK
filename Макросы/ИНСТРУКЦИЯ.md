# Подключение макросов к ЛНК_Реестры_v2.xlsx

## 1. Разложить файлы

Скопируйте на рабочий ПК (или в общую сетевую папку) вот такую структуру рядом друг с другом,
не меняя названия папок — макросы ищут их по путям "рядом с книгой":

```
ЛНК/
├── ЛНК_Реестры_v2.xlsx
├── Шаблоны/              ← 8 файлов .docx (Акт_ВИК, Протокол_УЗТ, ...)
└── Готовые/              ← создастся сама при первом формировании документа
```

## 2. Импортировать модули в книгу

1. Откройте `ЛНК_Реестры_v2.xlsx`.
2. Alt+F11 — откроется редактор VBA.
3. В дереве слева правой кнопкой по названию книги (VBAProject (ЛНК_Реестры_v2.xlsx)) →
   **Import File...**
4. По очереди импортируйте все 4 файла: `modConfig.bas`, `modChecks.bas`, `modGenerate.bas`, `modPrint.bas`.
5. Закройте редактор VBA.

## 3. Сохранить как книгу с макросами

Файл → Сохранить как → тип файла **Excel Macro-Enabled Workbook (*.xlsm)**.
С этого момента работайте именно с `.xlsm` файлом — обычный `.xlsx` макросы не хранит.

## 4. Разрешить макросы

При каждом открытии `.xlsm` Excel будет спрашивать про макросы, пока папка не станет доверенной:

Файл → Параметры → Центр управления безопасностью → Параметры центра управления безопасностью →
Надёжные расположения → Добавить новое расположение → указать папку `ЛНК/` (и поставить галку
«также доверять вложенные папки»). После этого макросы будут запускаться без предупреждений.

Если в организации макросы отключены групповой политикой независимо от этих настроек — обратитесь
к ИТ-специалисту, локально это не обойти (см. также предыдущее обсуждение в переписке).

## 5. Как пользоваться

- **Сформировать документ** — встаньте на нужную строку листа «Журнал», Alt+F8 → выберите
  `СформироватьДокумент` → Выполнить. Или назначьте кнопке на листе (Вставка → Фигура →
  правой кнопкой → Назначить макрос).
- **Собрать и напечатать пакет** — встаньте на любую строку нужного объекта в «Журнале» (документы
  по нему должны быть уже сформированы), запустите `СобратьИНапечататьПакет`.
- **Пакетная печать по методу** — `ПечатьПоМетоду`, впишите метод (ВИК/УЗТ/…) — напечатает все
  готовые документы этого метода из папки «Готовые».

## Важно — то, что макрос не может сделать при вашем наборе программ

Свидетельства о поверке и квалификационные удостоверения — отдельные сканы/PDF, а не файлы Word.
Без Adobe Acrobat (только Reader) и без прав на установку ПО программно склеить их в один
пронумерованный файл с актами и протоколами нельзя. Решение: печатаете их отдельно из Adobe
Reader и подкладываете в собранный пакет вручную в нужном месте — сквозная нумерация из макроса
рассчитана на страницы актов/протоколов, эти вложенные страницы нумеруются отдельно или от руки,
как решите по факту (см. шаг 6-7 на листе «Меню»).

## Проверка перед боевым использованием

Эти макросы написаны и проверены на корректность кода, но **не запускались в реальном Word** —
в среде, где я их готовил, нет Windows/Word для живого теста. Перед тем как полагаться на них
в рабочем процессе:

1. Сформируйте документ по 2-3 строкам разных методов, откройте результат — проверьте, что
   все поля подставились туда, куда нужно, и ничего не съехало.
2. Проверьте `СобратьИНапечататьПакет` на объекте с 2-3 документами — посмотрите на итоговую
   нумерацию страниц (особенно что на первой странице номера нет, а печать идёт с правильным
   количеством копий).
3. Если что-то работает не так — опишите точно, что увидели, и это будет быстро поправить.

## Известные баги в вашем старом макросе (для справки, если решите не переходить на новый)

Если предпочтёте продолжать пользоваться старым `...2026.xlsm`, минимум нужно поправить:

1. Удалить/переименовать один из двух одноимённых `Sub ПЕЧАТЬ_ПРОТОКОЛОВ()` (он есть и в Module2,
   и в Module4 — VBA не компилирует проект с двумя процедурами с одинаковым именем).
2. В Module2 функция `CheckPrintQueue` объявлena внутри `Sub` — так в VBA нельзя, надо вынести
   отдельным модулем или удалить.
3. Убрать модуль `Лист1.cls` (`CommandButton1_Click`) — там пути результата указывают прямо на
   файлы шаблонов, при запуске он их перезапишет.
4. Путь `D:\TEST VBA EXCEL\...` заменить на путь относительно книги (как сделано в новых модулях).
5. В именах генерируемых файлов зашит «2025» — поправить на переменную с текущим годом.

Без пунктов 1-2 макросы не запускаются вообще — ни один, включая рабочие.
