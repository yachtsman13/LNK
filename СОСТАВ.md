# Состав проекта

**Версия 4.0** — что в неё вошло и чего ещё нет, см. `ИЗМЕНЕНИЯ.md`.

## Как устроена программа
`Приложение/ЛНК.html` — один самодостаточный HTML-файл, открывается с диска
или флешки в браузере Chrome/Edge, без установки и без сети. Данные хранятся
в IndexedDB браузера. Документы `.docx` и `.xlsx` программа собирает своим
кодом (ZIP без сжатия) — внешние библиотеки не нужны.

Собирается скриптом:

    python3 scripts/export_json.py   # данные          → Приложение/данные.json
    python3 scripts/export_ppr.py    # план-график ППР  → Приложение/ппр.json
    python3 scripts/export_pg.py     # планы-графики    → Приложение/планы.json
    python3 scripts/build_app.py     # исходник+данные  → Приложение/ЛНК.html

Номер версии — в `scripts/export_json.py` (`"версия": "4.0"`), оттуда попадает
в `Приложение/данные.json` и показывается в шапке HTML-файла.

## Что в репозитории

### `Приложение/` — готовое приложение
| Файл | Описание |
|---|---|
| `ЛНК.html` | собранное приложение (~3 МБ) |
| `ЛНК.html.sha256` | контрольная сумма для автообновления с флешки |
| `данные.json` | метаданные (версия, дата сборки) |
| `исходник/` | исходники: `стили.css`, `страница/*.html`, `код/NN_*.js` |
| `исходник/порядок.txt` | порядок склейки исходников в один HTML |

### `scripts/` — сборка и проверка
| Файл | Описание |
|---|---|
| `build_app.py` | собирает `ЛНК.html` из исходников + данных |
| `export_json.py` | метаданные → `данные.json` |
| `export_ppr.py` | план ППР → `ппр.json` |
| `export_pg.py` | планы-графики → `планы.json` |
| `check_app_security.js` | проверка подписей, паролей, совместимости |
| `проверка_программы.js` | E2E-тесты: все разделы, выгрузки, хранилище |
| `проверка_печати.py` | проверка вёрстки PDF (pymupdf): нет висящих строк, разорванных разделов |
| `проверка_docx.py` | проверка структуры `.docx` (lxml) |
| `проверка_xlsx.py` | проверка структуры `.xlsx` (lxml) |
| `requirements.txt` | Python-зависимости |

### `ТЗ/` — техническое задание
| Файл | Описание |
|---|---|
| `*.md` | ТЗ, ответы заказчика, проработки |

## Папки с документами (флешка)
Внутри папки с документами программа использует следующие папки:

| Папка | Для чего |
|---|---|
| `ЛНК` | файлы обмена между рабочими местами |
| `Рез` | резервные копии |
| `Програм` | новая версия программы |
| `Вх` | новые файлы — программа разбирает сама |
| `Док ЛНК` | пункты перечня для аттестации (НОАЛ) |
| `Архив` | истёкшие и заменённые документы |
| `Прочее` | акты за период, пачки к акту |

При выгрузке для аттестации/проверки (НОАЛ) названия папок внутри
`Док ЛНК` подставляются полные — как в перечне документов.

## Чего в репозитории нет
**Excel-версии.** Разработка ведётся только для HTML-приложения.
Все разделы реализованы в `Приложение/исходник/код/` и собираются
в один HTML-файл.
